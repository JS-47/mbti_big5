# MBTI + 大五人格融合测试

一个可直接本地运行的单页前端应用，基于 **HTML + CSS + Vanilla JavaScript** 实现。

## 本地运行
1. 下载或克隆本项目。
2. 直接双击 `index.html` 用浏览器打开即可运行。
3. 如需本地服务方式，可执行：
   ```bash
   python3 -m http.server 8000
   ```
   然后访问 `http://localhost:8000`。

## 文件结构
- `index.html`：页面结构（欢迎页 / 测试页 / 结果页）
- `style.css`：界面样式与移动端适配
- `script.js`：题库、交互流程、计分逻辑、融合规则引擎、图表渲染
